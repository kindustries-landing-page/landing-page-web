# Rule: Generating a Product Requirements Document (PRD)

## Goal

To guide an AI assistant in creating a detailed Product Requirements Document (PRD) for web features.

## Process

1. **Understand UI/UX Scope**: Features, components, routes, responsiveness.
2. **Ask Clarifying Questions**: Limit to 3-5 critical questions.
3. **Generate PRD**: Clearly document components, state requirements, API integrations.
